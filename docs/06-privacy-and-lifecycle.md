# 06 — Privacy & Lifecycle

The separation of private and shared data, and what happens when users leave threads,
relationships, or delete their data. The trust foundation of the product.

---

## 16. Visibility and Privacy

The app separates private and shared data.

### Private

- Typed drafts
- AI message reviews
- User edits before sending
- Private coaching notes
- Private AI observations
- Private emotional-state detection
- Private communication profile fields

### Shared

- Sent messages
- Thread name
- Thread status
- Shared mediator messages
- Shared relationship patterns
- Shared summaries
- Safety-state messages

The recipient only sees the final sent message.

**They do not see:**

- Original draft
- AI review
- Rejected suggestions
- Prior edits
- Private coach comments

Because the entire app is AI-assisted, each message does not need an "AI-assisted" label.

---

## 17. Deletion and Exit

The app supports:

- User exits a thread
- User exits a relationship
- User deletes their own copy
- Either user requests shared deletion
- Both users must agree to delete shared chat history for both sides
- Private coaching data remains owned by the individual user
- Shared messages remain visible unless both users delete the shared conversation

This mirrors normal chat expectations while preserving individual ownership.
