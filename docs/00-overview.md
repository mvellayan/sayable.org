# 00 — Product Overview

## Product definition

**BetterVibe is an AI-assisted communication app for emotionally important conversations.
It helps people say hard things in a way the other person can actually hear. It works
like a normal chat app with a quiet emotional intelligence layer.**

The app is initially focused on romantic couples, but the data model should support
relationships more generally.

## The three AI roles

1. **My Coach** — private to User A.
2. **Their Coach** — private to User B.
3. **Shared Mediator** — visible to both users.

The AI should surface only when it has a useful nudge.

## Key product principle

**BetterVibe should reduce emotional load, not add process load.**

That means:

- No heavy worksheets.
- No forced check-ins.
- No complicated mediation process.
- No constant AI interruptions.
- No "therapy app" feeling.

The product should feel like:

**A normal chat app with a quiet emotional intelligence layer.**

The AI appears only when it can help:

- Pause before sending
- This may land as blame
- You may be talking past each other
- They may need reassurance, not logistics
- Summarize where we are?
- Help me respond?
- Ask a clarifying question?
