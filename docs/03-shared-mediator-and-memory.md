# 03 — Shared Mediator & Relationship Pattern Memory

The shared, two-sided intelligence: a neutral mediator visible to both users, and the
memory of recurring patterns across the relationship.

---

## 9. Shared Mediator

The Shared Mediator is visible to both users.

**It can:**

- Summarize where the conversation is
- Identify common ground
- Identify unresolved issues
- Suggest a pause
- Suggest a repair attempt
- Detect circular arguments
- Name the pattern neutrally
- Name a coercive or pressuring dynamic neutrally
- Recommend an offline conversation
- Flag safety concerns

**It must not:**

- Take sides
- Reveal private coaching
- Reveal drafts
- Diagnose either user
- Decide who is right
- Pressure forgiveness
- Pressure reconciliation

**Independent by construction.** The Shared Mediator forms its own assessment
from the shared *sent* messages only. It never reads either person's drafts,
private coaching, observations, or private profile. This independence is what
lets it surface a coercive or pressuring dynamic without becoming a channel that
leaks one side's private read to the other. The structural protection for the
person being pressured lives here — in a neutral view both people can see — not
in either coach.

---

## 10. Relationship Pattern Memory

The app remembers recurring patterns.

**Examples:**

- One person feels unheard
- One person feels attacked
- One person withdraws
- One person over-explains
- Conversation becomes circular
- Logistics hide emotional hurt
- Apology turns into defense
- Boundary is heard as rejection
- Request is heard as criticism

**Storage rules:**

- If the observation is about one user, it belongs in that user's private profile / AI
  observations.
- If the observation is about the relationship dynamic, it belongs in shared
  relationship pattern memory.

Users should be able to view, edit, hide, or delete AI observations.
